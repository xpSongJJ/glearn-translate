# 基本配置

## 主界面

- 文本输入：默认单行，Enter 翻译，Ctrl / ⌘ + Enter 换行。
- 目标语言：智能、中文、英语、日语、韩语、法语、俄语。
- 智能：目标语言留空，由 AI 判断原文的主要语言，中文译为英语，其它语言译为中文。只有目标语言留空时才启用智能规则。
- 主题、译文缓存和清除缓存。

## 更多

“模型 API”集中配置服务商、密钥、接口与模型。设置自动保存。

主界面可设置主题和缓存；“更多”中通过 System Prompt／User Prompt 标签切换编辑，一次只显示一个输入框，默认显示 8 行并随内容增高至 12 行。切换时保留内容，继续自动保存；恢复默认仅作用于当前提示词。选中 User Prompt 后，可悬浮提示图标查看 `{{to}}`（目标语言）与 `{{origin}}`（原文）占位符说明。
