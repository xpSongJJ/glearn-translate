# 功能介绍

## 插件内文本翻译

顶部输入框默认单行，输入多行时自动增高。Enter 打开与划词翻译共用的译文卡片，Ctrl / ⌘ + Enter 换行。支持流式显示、复制与失败重试。
快捷键说明在首次成功翻译后自动隐藏，再次打开插件时不再显示。复制成功以短暂的勾选图标反馈，卡片高度保持不变；复制失败仍显示错误提示。

## 划词翻译

选中文本后点击、键盘激活或悬停翻译圆点查看结果。默认词条按“词头与音标＋每个词性单独一行”展示；自定义提示词保持其输出格式。
切换选区会取消旧请求，避免旧译文覆盖新选区。

## 常用设置

主界面可设置目标语言、主题、译文缓存，并清除缓存。动画与过渡默认启用。
主题通过“系统／浅色／深色”三段按钮切换。模型使用同一个输入框搜索、选择或直接输入模型 ID，输入后按 Enter 确认。
“更多”中直接展示模型 API 和提示词区，通过 System Prompt／User Prompt 标签切换，一次只编辑一项。编辑框显示 8 至 12 行，切换保留内容并自动保存；恢复默认仅作用于当前项。User Prompt 后的提示图标可悬浮查看占位符说明。插件总开关与划词显示模式已移除，旧配置中的关闭状态不再影响划词翻译。

选择“智能”时，设置中的目标语言保持为空，发送请求前由插件明确翻译方向：主要为汉字的文本译为英文，英语等其它语言译为简体中文；包含日文假名或韩文的文本译为简体中文。判断忽略空白和标点，支持单字选区。手动指定语言时以所选目标为准。普通聊天模型与千问 MT、混元翻译等专用翻译模型使用相同的目标语言规则。

默认提示词要求英语词条第一行显示“单词 /音标/”，之后每个词性及其简短词义各占一行，同一词性的不同词义使用分号分隔；目标为中文时，词义必须为中文。英美读音不同时，第一行使用“单词 英 /音标/ 美 /音标/”，相同时只保留一份音标。分类时忽略单词周围的空白、引号、括号及逗号、句号等标点；词内撇号、连字符保留。多词短语（包括 machine learning 等复合术语）仅输出译文，不附词头和音标。默认流式聊天服务还会整理词条中粘在一起的词性行，保留同一词性的分号和音标。未修改过的旧默认提示词会自动升级，自定义提示词保持不变，也可通过“恢复默认 Prompt”使用新规则；旧缓存随规则版本失效。专用翻译模型若不支持提示词，其返回内容取决于服务能力。
音标规则同时检查原文与译文：原文为英语单词，或中文等其他语言译成单个英语单词时，英文单词后均须带音标。智能模式与手动选择英语时都适用，完整英语句子和段落不逐词附音标。

划词卡片右上角的固定图标可保留当前卡片；固定后移开鼠标、点击页面、改变选区或滚动页面均不会关闭或替换卡片。取消固定后恢复自动隐藏，关闭按钮可随时关闭卡片。

翻译失败时按原因提供操作：检查密钥、更换模型、检查配置、重试或刷新页面。插件面板内直接进入配置，网页划词卡片通过独立标签页打开对应配置。

## 功能调整

不再提供机器翻译、全文翻译、网页段落悬浮翻译、网页输入框翻译、全文悬浮球和相应快捷键。
