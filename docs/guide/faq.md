# 常见问题

## Ollama 配置问题

在“更多 → 模型 API”选择“自定义接口”，输入完整接口地址，例如 `http://localhost:11434/v1/chat/completions`，填写本地已安装的模型名称。
本地服务不要求密钥时，API Key 可以留空。确保服务允许浏览器扩展来源的请求。

## 获取列表失败

检查密钥、网络与接口地址，也可直接手动填写服务商提供的模型 ID。
Azure 部署和腾讯混元翻译使用手动模型配置。

## 旧版配置迁移

升级时自动迁移浏览器中已保存的旧配置。AI 配置会保留，机器翻译和网页翻译配置会移除。
原来选中机器翻译时，会优先切换到已有密钥的 AI 服务；未配置 AI 时需要先填写密钥与模型。

## 网页没有翻译圆点

更新扩展后，刷新已经打开的网页。浏览器内部页面和扩展商店等受限页面不能注入划词组件。
超过 4096 字符的选区暂不显示圆点，可分段选择或使用插件内文本翻译。

## 费用与隐私

插件免费，AI 服务可能计费。密钥保存在当前浏览器；翻译文本和密钥会发送给你配置的服务。
